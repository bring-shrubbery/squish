# Squish website

The one-page site at https://squish.quassum.com: an Astro static site that mirrors the
repository README, offers the latest release for download, and owns the URLs the app
depends on (`/appcast.xml` redirects to the Sparkle feed on GitHub Releases).

## Develop

```sh
cd web
npm install
npm run dev        # http://localhost:4321
npm run check      # astro check (types)
npm test           # vitest
npm run build      # writes dist/
npm run preview    # serves dist/ (without the _redirects rules)
```

The download button is rendered at build time from the latest GitHub release (the
`Squish-vX.Y.Z-macos-arm64.dmg` asset). When the API is unreachable or throttled, or there is
no release yet, the button links to the Releases page instead; the build never fails because
of it. Set `GITHUB_TOKEN` in the environment (any token, no scopes needed) to lift the
unauthenticated rate limit.

`public/og.png` is generated by `python3 scripts/og-image.py` (needs Pillow).

## Deploy

`wrangler.jsonc` describes an assets-only Worker named `squish-web`: there is no Worker code,
only `dist/` plus the `_headers` and `_redirects` files from `public/`. `workers_dev` is off,
and the `routes` entry attaches the custom domain `squish.quassum.com` on deploy (the
`quassum.com` zone must be on the same Cloudflare account).

```sh
npm run build
npx wrangler deploy
```

### Automatic deploys (GitHub Actions)

`.github/workflows/web.yml` runs the same two commands on every push to `main` that touches
`web/`, and the Release workflow dispatches it after each app release so the download button
offers the new version. It needs two repository secrets:

- `CLOUDFLARE_ACCOUNT_ID`: the account that owns the `quassum.com` zone
  (`npx wrangler whoami` prints it).
- `CLOUDFLARE_API_TOKEN`: a token from *My Profile → API Tokens → Create Token*, using the
  *Edit Cloudflare Workers* template, scoped to that account and the `quassum.com` zone.

```sh
gh secret set CLOUDFLARE_ACCOUNT_ID --body <account id>
gh secret set CLOUDFLARE_API_TOKEN          # paste the token
```

Without them the Website workflow fails at its first step and names the missing secret.

## Check a deployment

```sh
curl -I https://squish.quassum.com/appcast.xml   # 302 to the GitHub asset
curl -I https://squish.quassum.com/download      # 302 to the Releases page
```
